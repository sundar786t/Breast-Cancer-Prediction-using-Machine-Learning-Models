# 🩺 Breast Cancer Prediction using Machine Learning Models

This project focuses on predicting **breast cancer diagnosis** using multiple **machine learning algorithms**. By analyzing features of cell nuclei, the models classify tumors as **benign** or **malignant** to assist in early cancer detection.

---

## 🚀 Features
- Dataset preprocessing & feature scaling  
- Implemented multiple ML models:  
  - Logistic Regression  
  - Support Vector Machine (SVM)  
  - Random Forest  
  - K-Nearest Neighbors (KNN)  
  - Decision Tree  
- Model evaluation using:  
  - Accuracy  
  - Confusion Matrix  
  - ROC-AUC curve
